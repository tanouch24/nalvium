# NALVIUM — Store assets checklist

À produire à partir de captures réelles, sans données utilisateur fictives.

## Android

- [ ] Icône adaptive et icône legacy
- [ ] Feature graphic
- [ ] Captures téléphone : Accueil, Diagnostic, Assistant, Ma Maison, Équipement, Avant/Après, Communauté, Safety/professionnel
- [ ] Nom NALVIUM, courte description et description complète
- [ ] Catégorie et classification de contenu
- [ ] Privacy Policy URL et support contact confirmés
- [ ] Data Safety vérifiée sur la build exacte
- [ ] Piste de test interne/fermée et notes de test

## iOS

- [ ] App icon et variantes requises
- [ ] Captures iPhone par taille
- [ ] Nom, sous-titre, description et mots-clés
- [ ] Support URL, Privacy URL et CGU
- [ ] App Privacy vérifiée sur la build exacte
- [ ] Notes de review : rôle de l’IA, safety stops, absence de marketplace et état des publicités

Les captures ne doivent pas exposer de photo, conversation, document, numéro de série, adresse ou autre donnée personnelle réelle.
