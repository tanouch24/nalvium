# NALVIUM — RÉSEAU PROFESSIONNELS

## Objectif V1

Permettre à NALVIUM d’orienter un utilisateur vers un professionnel sans construire immédiatement une marketplace complexe.

## Profil professionnel

Champs :
- id
- nom commercial
- raison sociale
- métier(s)
- SIREN/SIRET si applicable
- téléphone
- email
- adresse pro
- zones desservies
- rayon
- horaires/disponibilité déclarée
- statut vérification
- actif/inactif
- mode de facturation futur

## Métiers initiaux

- plombier
- réparateur électroménager
- artisan multiservice
- électricien pour cas orientés pro

## Distribution d’un lead

V1 :
- règles géographiques ;
- métier ;
- disponibilité déclarée ;
- statut actif ;
- capacité éventuelle.

Aucune affirmation « disponible dans 30 minutes » sans donnée réelle.

## États lead côté pro

- new
- viewed
- accepted
- declined
- contacted
- won
- lost
- expired

## Anti-spam

- limitation du nombre de pros recevant un lead ;
- consentement utilisateur ;
- historique des attributions ;
- blocage professionnels abusifs ;
- mécanisme de plainte.

## V2

- application/espace Pro ;
- paiement ;
- crédits/leads ;
- abonnement ;
- calendrier ;
- avis après intervention ;
- disponibilité temps réel.
