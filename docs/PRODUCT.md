# NALVIUM — PRODUCT

## Proposition

NALVIUM aide gratuitement un particulier lorsqu’un objet ou un équipement de la maison ne fonctionne plus.

Promesse :
**Montrez le problème. Nalvium vous guide.**

NALVIUM doit réduire trois frictions :
1. « Je ne sais pas ce qui ne va pas. »
2. « Je ne sais pas si je peux le réparer moi-même. »
3. « Si je dois appeler quelqu’un, je ne sais pas qui ni comment lui expliquer le problème. »

## Utilisateur principal

Particulier confronté à un problème domestique, souvent pressé, peu technique et utilisant son téléphone à proximité du problème.

## Jobs-to-be-done

- comprendre rapidement un problème ;
- savoir si la situation semble urgente ;
- tenter uniquement une action simple et sûre ;
- être guidé sans jargon ;
- montrer une nouvelle photo plutôt que tout expliquer ;
- obtenir un professionnel si nécessaire ;
- transmettre au professionnel un résumé utile sans répéter toute l’histoire.

## Proposition de valeur

### Pour le particulier
- gratuit ;
- réponse immédiate ;
- visuel ;
- guidage étape par étape ;
- possibilité d’arrêter et demander un pro.

### Pour le professionnel
Un lead déjà contextualisé :
- catégorie ;
- description ;
- photos consenties ;
- actions déjà tentées ;
- localisation approximative/zone ;
- créneau souhaité ;
- coordonnées consenties.

## Monétisation

Pas de paywall particulier V1.

Sources futures :
1. lead qualifié facturé au professionnel ;
2. abonnement professionnel ;
3. affiliation pièces/outils lorsque pertinente et clairement indiquée ;
4. partenariats B2B.

La recommandation technique ne doit jamais être dégradée pour maximiser une commission.

## Catégories V1

### Plomberie
Fuites simples, robinetterie, chasse d’eau, siphon, évacuation simple.

### Électroménager
Lave-linge, lave-vaisselle, réfrigérateur, four et appareils courants : identification, codes erreur, vérifications accessibles et sûres.

### Bricolage
Fixations, petits dommages, identification de pièces/consommables et opérations simples.

### Électricité
V1 = reconnaissance/orientation et sécurité. Pas de guidage d’intervention risquée sur installation sous tension.

## Hors scope V1

- marketplace temps réel avec prix garantis ;
- paiement des interventions dans l’app ;
- promesse de diagnostic professionnel ;
- assurance/garantie ;
- intervention gaz DIY ;
- réparation automobile ;
- chantier structurel ;
- diagnostic réglementaire immobilier.

## Acquisition organique / site public

`nalvium.com` est un canal produit et acquisition. Deux intentions principales :

1. **Problème** : « fuite sous évier », « lave-linge ne vidange plus », etc. → contenu utile → diagnostic NALVIUM.
2. **Professionnel local** : « plombier Lyon », « réparateur électroménager Paris », etc. → page locale utile → aide NALVIUM et/ou demande de professionnel.

Le site ne doit pas créer de faux annuaires ni prétendre qu’un professionnel est disponible sans donnée réelle.

## North Star

**Nombre de problèmes résolus de manière sûre ou correctement orientés vers un professionnel.**

NALVIUM doit inspirer :
- utilité ;
- calme ;
- compétence ;
- transparence.

Pas de ton magique « l’IA sait tout ». Formulation type :
« D’après ce que je peux voir, la cause la plus probable est… Vérifions un point avant de continuer. »
