# NALVIUM — Visual Map

Ce pack impose les visuels et leur rôle. `install-visuals.sh` télécharge les fichiers Pexels dans `public/images/nalvium/`.

| Fichier | Usage principal | Règle de texte |
|---|---|---|
| plumbing/faucet-drip.jpg | mosaïque « robinet qui goutte » + guide robinet | La goutte est visible : on peut parler de robinet qui goutte. |
| laundry/washing-machine.jpg | grande démo lave-linge / catégorie électroménager | Ne pas inventer d'eau dans le tambour ; parler d'un problème de cycle/vidange seulement comme question utilisateur. |
| appliances/dishwasher.jpg | guide lave-vaisselle | Lave-vaisselle ouvert visible ; ne pas inventer d'eau stagnante. |
| appliances/refrigerator.jpg | guide réfrigérateur | Réfrigérateur ouvert visible ; ne pas prétendre observer une température. |
| appliances/oven.jpg | guide four | Four domestique visible ; panne déclarée par l'utilisateur, pas « observée » visuellement. |
| bathroom/toilet.jpg | mosaïque WC + guide chasse d'eau | WC visible ; ne pas prétendre voir une chasse qui coule si ce n'est pas visible. |
| electrical/outlet.jpg | sécurité / catégorie électricité | Prise domestique ; uniquement vérifications externes sûres. |
| diy/tools.jpg | catégorie bricolage | Petit bricolage / outils, sans promesse de diagnostic visuel précis. |
| home/laundry-water-heater.jpg | passage Pro / chauffage | Buanderie + chauffe-eau visibles ; ne pas inventer une panne visible. |

## Important

- Ne jamais utiliser une photo comme preuve d'un défaut qu'elle ne montre pas.
- Le hero « fuite sous évier » existant doit être remplacé seulement lorsqu'une photo sous-évier réellement pertinente est disponible ; ne pas recycler `faucet-drip.jpg` comme faux siphon.
- 01→04 : photo générale → crop/observation → question UI → écran action. L'étape 04 n'a pas besoin d'une photo.
- Ma Maison : conserver la photo actuelle si elle est meilleure que les visuels de ce pack.
- Ne pas utiliser une image principale dans plus de deux emplacements visibles.
